# 动漫搜索与自动追番：使用教程

## 这是什么

这是给能够运行本机脚本的 AI Agent 使用的工具，不是独立播放器，也不是资源存储站。
你用自然语言说出需求，Agent 识别作品、在 Nyaa 查找发布，再核对季集、体积、字幕和资源详情。
默认给出符合条件的结果；可选接入 qBittorrent 下载、宿主定时任务和 Bangumi 个人番单。

以 Codex 和 DSH 为使用示例；其他能加载 skill、运行 Python 并访问网络的 Agent
可能需要少量宿主适配。普通网页聊天并不等于具备本机执行能力。

## 第一次怎么开始

先在宿主中选择这个 skill，或直接说“使用动漫搜索与自动追番”。第一次交互调用会给出
固定简介和尚未配置项的提示；没有必填账号，不会自动弹出设置窗口。

| 你要做什么 | 可以直接说 |
| --- | --- |
| 试一次搜索，不下载 | 找《作品名》第 3 集，只要磁力，不下载 |
| 输入简称 | 找《你常用的简称》；有版本歧义时再补季数或年份 |
| 找老番全集 | 找《作品名》第一季完整合集，普通观看 |
| 找电影 | 找《电影名》的蓝光资源，只要磁力 |
| 必须有中文 | 找《作品名》第 3 集，必须有中文字幕 |
| 直接提交下载 | 找《作品名》第 3 集，合格后提交到 qBittorrent |

作品名、年份和集数按你的需求替换。不必自己翻译成英文发布名，也不必记命令行参数。
一条消息可以列出多部作品，建议用顿号或分行写清楚，避免把两个片名连成一个。
老番通常会先给出少量合格选项；可以明确说“按默认推荐选一个”省去选择步骤。

## 画质与字幕

| 档位 | 默认正篇体积要求 |
| --- | --- |
| 轻量观看（默认） | 1–2 GiB/集，最低 1 GiB |
| 普通观看 | 2–4 GiB/集 |
| 高画质 | 通常至少 6 GiB/集，或经核验的 BDMV、Remux 等来源规则 |

这些是筛选偏好，不是“文件越大画面一定越好”。默认轻量观看允许向上兼容，优先档内
资源；不会为了找到结果自动降低下限。显式指定的上限仍严格执行。
整季包核对正篇覆盖和逐集体积，不拿总容量平均值冒充每集达标；电影默认总容量至少
10 GiB。找不到合格资源或检查未完成时会如实说明，不把未验证当作不存在。

你也可以直接说“每集至少 1 GiB，不设上限”或“每集 2–4 GiB”。档位变更需要明确
决定；明确的自定义体积要求优先。详细规则见 [画质与筛选](quality-ranking.md)。

不特别要求时，中文字幕只是偏好；“多字幕”不代表已确认有中文。
说“必须有中文字幕”才会把中文当作硬条件，简体和繁体都接受。
这项 skill 核验发布资源是否带中文，不承担外挂字幕下载、翻译或校轴。

## 下一集、最新集和下载进度

- 对已追踪的新番，只说片名默认找本地记录中的下一目标集，不等于找网站种子最多的集数。
- “最新一集”与“下一集”不同；想重找某集就明确说“第 3 集”，不会因重找旧集让进度倒退。
- “只要磁力，不下载”不提交客户端，也不推进本地交付进度。
- 正篇提交被客户端核验接受后才按现有规则更新进度；搜到候选、添加失败或等待核验不算完成。
- “客户端接受任务”不等于视频已经下载完，也不等于实际播放看完。
- 老番、整季和电影不会因为一次搜索就自动加入新番追踪记录。

## 两个可选配置窗口

**Bangumi：** 说“连接 Bangumi”，Agent 打开 Token 小窗口。到
[官方令牌页面](https://next.bgm.tv/demo/access-token) 创建 Access Token，粘贴到本机窗口，
点击“验证并连接”。令牌不发进聊天；验证失败不会覆盖原有绑定。

**qBittorrent：** 说“配置 qBittorrent”，先检测现有客户端。需要手动指定时打开小窗口，
选择程序和下载目录。程序留空可自动检测，目录留空使用宿主默认值。
这不会自动安装客户端，也不会替你开始下载。远程 Web API 需要另行配置。

小窗口需要本机桌面和 Python Tk；远程或无桌面环境可以使用私密文件、环境变量方式，
由 Agent 按 [Bangumi 配置](bangumi-sync.md) 和 [客户端配置](client-readiness.md) 引导。
Codex 和 DSH 的记录、配置与授权分别保存，不会因安装插件自动互相复制。

## 自动追番

可以说：“每周六晚上 10 点检查《作品名》的下一集，必须有中文字幕，找到后提交到 qBittorrent。”

Agent 会通过宿主的定时任务能力创建计划，并说明具体时间和条件。宿主需支持计划任务，
任务执行环境需有网络、脚本与客户端访问能力；离线、关闭应用是否还能运行取决于宿主，
不是安装 skill 后就有独立后台服务。定时运行不弹配置窗口。修改或停止计划也直接用自然语言说。

## Bangumi 能做什么

连接后可以说：

- “看看我 Bangumi 正在看哪些番，各看到哪里了。”
- “结合我看过的番、评分和短评，推荐几部没看过的。”
- “这部番第 6 集看完了，记到 Bangumi。”
- “这部番已经全部看完，更新一下收藏状态。”

Bangumi 是可选的个人资料与记账镜像，不会接管本地找番目标或画质决定。按本 skill 的
约定，已核验接受的追番正篇交付会同步为已看；这是自动记账约定，不是检测到实际观看。
仅返回链接、提交失败、整季或电影下载不自动推断逐集观看，可明确说看完后写回。
云端同步失败可稍后重试，不会把有效的本地下载结果取消。当前读取收藏短评，不包含长篇日志。

## 给 Agent 的教程输出约定

用户只问“怎么用”时，用 `python scripts/first_use.py --guide` 取得简明固定介绍，再按
所问主题补充本页内容；不要默认全文粘贴。本页示例不是执行搜索、创建计划或写回进度的授权。
首次引导在同一对话只提示一次，之后只有用户问教程或设置时才展开。不会为展示教程启动窗口、
调用远程番单、创建记录或尝试下载。资源使用请遵守所在地规则和相关授权。
